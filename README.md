# Miao Website

Static website for **Miao** — an all-you-can-drink boba shop in Carrollton, TX. 100% customizable drinks, local artist merch, open until 2AM.

## Structure

```
miao-website/
├── index.html
├── css/
│   ├── reset.css
│   ├── tokens.css
│   └── style.css
├── js/
└── assets/
```

## Development

No build step required. Open `index.html` directly in a browser or use a local server:

```bash
npx serve .
```

## Deployment

Push to the `main` branch. The site is plain HTML/CSS/JS with no dependencies.
